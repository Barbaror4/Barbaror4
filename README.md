./projects

"MAGICEMU" (https://github.com/Barbaror4/MAGICEMU)

Retro emulation and multimedia on the STM32F746G-DISCO. A hands-on project exploring what an embedded Cortex-M7 platform can do with limited resources.

- NES emulation, DOOM, and Wolfenstein 3D
- Audio playback and multimedia features
- Display, storage, and peripheral integration

"Linux on STM32F7-DISCO" (https://github.com/Barbaror4/linux-stm32f7-disco)

A Linux 2.6.33 uClinux/NOMMU port for the STM32F746G-DISCO, exploring Linux on a Cortex-M7 microcontroller without an MMU.

- Embedded Linux on resource-constrained hardware
- SD-based root filesystem and BusyBox
- Low-level board support and peripheral integration
